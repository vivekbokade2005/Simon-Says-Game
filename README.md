# Simon Says Game 🎮

A browser-based **Simon Says memory game** built using **HTML, CSS, and JavaScript**. The game challenges players to remember and repeat an increasing sequence of colors.

## 📌 About the Project

This project is a simple implementation of the classic Simon Says memory game. With each level, the sequence becomes longer, requiring the player to remember the previous pattern and select the correct buttons in the same order.

## ✨ Features

* Interactive color buttons
* Increasing difficulty with each level
* Score/level tracking
* Game-over detection
* Restart functionality
* Responsive and simple interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Press any key to start the game.

## 🎯 Purpose

This project was created to practice **JavaScript logic, DOM manipulation, event handling, and game development concepts.
